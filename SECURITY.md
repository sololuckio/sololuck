# Security Policy

## Security maintainer

[@sololuckio](https://github.com/sololuckio) is the owner, operator, and security maintainer of SoloLuck, responsible for reviewing vulnerability reports and coordinating security fixes for this repository.

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub: [open a private vulnerability report](https://github.com/sololuckio/sololuck/security/advisories/new) (a GitHub account is required). Only you and the repository's maintainers can see the report. Please do not open a public issue for a security problem.

## Scope

This policy covers the code published in this repository. It does not grant permission to test third-party systems or disrupt the live sololuck.io service.
